# Checklist de entrega e testes

- [x] HTML com estrutura semântica e idioma pt-BR.
- [x] CSS responsivo para desktop e mobile.
- [x] Paleta com cinco cores hexadecimais e justificativas.
- [x] Tipografia documentada.
- [x] Menu mobile com abrir/fechar.
- [x] Animações de entrada com IntersectionObserver.
- [x] Respeito à preferência de movimento reduzido.
- [x] Texto alternativo nas imagens do ambiente.
- [x] Links de menu/reservas direcionados ao site oficial.
- [x] Três imagens originais do briefing preservadas em `assets/referencias/`.
- [x] Pesquisa, prompts, decisões e pontos de revisão documentados.

## Limitações conhecidas
- A página é um protótipo conceitual independente, não um site oficial do restaurante.
- Fotos de sushi e coquetéis vêm de URLs externas do Unsplash e são placeholders; precisam de internet.
- As informações institucionais foram consultadas no site oficial, mas devem ser novamente verificadas antes de qualquer publicação real.
