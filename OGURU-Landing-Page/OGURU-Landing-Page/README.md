# OGURU Sushi & Bar — landing page conceitual

Landing page responsiva criada como exercício de vibecoding e identidade visual, inspirada nas fotos de ambiente enviadas e nas informações públicas do site oficial do OGURU.

## Como abrir

1. Extraia a pasta do projeto.
2. Abra `index.html` no navegador. Para melhor experiência de desenvolvimento, use a extensão **Live Server** no VS Code.
3. As fotos de ambiente fornecidas estão em `assets/referencias/`. As imagens de sushi e drinks usam URLs externas do Unsplash; precisam de internet para carregar.

## Estrutura

- `index.html` — conteúdo e estrutura da página.
- `style.css` — identidade visual, layout responsivo, animações e estados de interação.
- `script.js` — menu mobile e animações de entrada por rolagem.
- `assets/referencias/` — três referências visuais recebidas no briefing.
- `docs/` — registro de pesquisa, decisões, paleta e prompts do processo.

## Nota

Este é um protótipo conceitual, não uma reformulação oficial publicada pelo restaurante. Links de reserva/menu apontam para o site oficial para evitar inventar um sistema de reserva ou dados de menu. Confirme conteúdo, horários, preços e links antes de usar comercialmente.
